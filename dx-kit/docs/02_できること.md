# dxkit でできること

## 一言で
「問い合わせの一次対応」と「請求書の入力作業」をAIが下準備し、人は例外と判断だけに集中できるようにします。

## できること
| 業務 | AIが行うこと | 人が行うこと |
|---|---|---|
| FAQで答えられる問い合わせ | 分類し、FAQを根拠に返信文を作成。条件を満たせば自動返信可として分類 | 運用開始後は抜き取り確認 |
| 見積依頼・一般問い合わせ | 分類と返信案作成、担当者への振り分け | 内容確認して送信 |
| 返金・クレーム・法務・不具合 | 担当部署へ自動で振り分け、状況を整理 | 判断と対応（AIは回答しない） |
| 請求書・領収書の入力 | 日付・金額・取引先をCSV化。読めない書類に印を付ける | 印の付いた分のみ確認 |
| 効果測定 | 削減時間・削減額を自動集計 | 経営への報告 |

## 期待できる効果（サンプル係数での目安）
- 問い合わせ1件あたり 8分 → 1.5分（自動解決分は0分）
- 書類1枚あたり 6分 → 0.5分
- 例: 月500件の問い合わせの4割が自動解決、残りを支援とすると、月約 50〜60 時間（時給3,000円で約15〜18万円）の削減。※実測値に置き換えて再計算してください

## できないこと（現時点）
- メール・Slack等の自動受信/実送信（出力はキューまで）
- 画像・PDFの直接読み取り（テキスト化が必要）
- FAQに無い内容の回答（その場合は必ず人間へ）
- 返金額の決定、法的判断、契約条件の約束

## 向いている会社
- 問い合わせが月100件以上、FAQで回答できる割合が高い
- 請求書・領収書の手入力が経理の負担になっている
- 小さく始めて効果を数値で確認したい
