# hrai でできること

専任の人事がいない中小企業で、**総務・人事の「同じ質問への回答」と「定型文書の下書き」**を減らします。判断は人が行います。

| 業務 | AIが行う | 人が行う |
|---|---|---|
| 社員からの規程質問（有給・休日・手当・育児介護など） | 規程の原文を引用して回答。記載が無ければ「記載なし」 | 規程の更新、ログ確認 |
| 個人の給与・評価・懲戒・健康・法律に関する質問 | **回答せず**担当者へ案内 | 個別対応 |
| 求人票・面接質問・社内通達の下書き | 下書きと自動チェック（差別表現・個人情報・未入力） | 文面を確認して承認 |
| 承認済み文書の送信（Slack／メール） | 承認済み・本文不変・宛先が許可内の場合のみ**システムが送信**し、記録 | 承認（送信前に文面を確認） |
| 人事評価の根拠整理（**点数は付けない**） | 日報の引用つき整理、育成の回数・時間、育成した相手の成果の変化を集計し、評価コメントを下書き | 評価の判断、最終コメントの記入、承認 |
| 勤怠・有給アラート | 未入力・残業の月末見込み・有給の取得遅れを数値で判定し、本人と上長への通知を下書き | 通知の確認・承認、必要な声かけ |
| 入社手続き | 入社のご案内、チェックリスト、期限超過の催促を下書き。進捗を管理 | 承認、書類の受領確認、**届出の実施と完了記録** |
| 求人応募の一次対応 | 受付返信、募集FAQへの回答、面接日程の候補提示を下書き | 1件ずつ確認・承認、**選考・合否・条件交渉** |
| 1on1の準備 | 前回の約束事・日報の引用・話題の候補をまとめる（評価ではない） | 面談の実施、メモ記入 |
| Slackでの質問・承認 | `/hr` で規程に質問（本人にのみ表示）、承認ボタンで承認・却下 | 承認（登録した承認者のみ） |
| 届出（社会保険・雇用保険・労基署等） | 行わない | **人が専用ソフト／e-Govで実施** |
| 退職手続チェックリスト | 項目の下書き | 社会保険手続・給与計算を専用ソフトで実施 |
| 効果測定 | 削減時間・金額の集計 | 実測値に基づく見直し |

## できないこと
給与・保険料の計算／届出の作成・提出／採否・懲戒の判断／応募者の選考・合否判断／**評価の点数・ランク・順位付け、昇給等の推奨、社員同士の比較**／法律相談／**未承認文書の送信**（承認前は送れない仕組み）。入口は現状CLIのみ。

## 期待効果（仮定値。`data/settings.json` で変更）
質問1件 10分→1分、下書き1件 45分→12分、時給2,500円。月100件の質問と10件の下書きなら 約 **16時間／約4万円** の削減（実測で必ず差し替えること）。

## 向いている会社
従業員数十名、専任人事なし、就業規則が電子化されている、社労士に相談できる。
